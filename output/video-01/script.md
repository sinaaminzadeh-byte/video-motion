# ویدئوی 01 — رابط فروشگاهی مدرن

بدون نریشن یا موسیقی؛ متن روی تصویر و زیرنویس با افکت‌های محلی همراه است. رابط ترب مفهومی است و قیمت‌ها فرضی هستند. هویت تصویری و نماد نواک بازسازی پیشنهادی است، نه لوگوی رسمی تأییدشده.

| زمان | متن روی تصویر |
|---|---|
| 0–4 ثانیه | مشتریات فقط توی اینستاگرام / دنبالت نمی‌گردن |
| 4–7 ثانیه | آدم‌ها قیمت محصولات رو / توی ترب مقایسه می‌کنن |
| 7–10 ثانیه | اگه اونجا نباشی، / رقیبت ممکنه باشه |
| 10–13 ثانیه | ترب مثل ویترین / یه پاساژ بزرگه |
| 13–17 ثانیه | مشتری مقایسه می‌کنه / و فروشگاهش رو انتخاب می‌کنه |
| 17–20.5 ثانیه | برای بخش خرید اینترنتی ترب / سایت فروشگاهی و اینماد لازمه |
| 20.5–25 ثانیه | با فروشگاه اینترنتی حرفه‌ای / مسیرهای جدید فروش باز می‌شن |
| 25–30 ثانیه | نواک وب / فروشگاه اینترنتیت رو بساز |

در صحنه ششم یادآوری می‌شود که ثبت‌نام و تأیید ترب نیز لازم است. CTA: سفارش طراحی فروشگاه. متن سناریوی ارسالی برای جلوگیری از تعمیم نادرست و ادعاهای اثبات‌نشده اصلاح شده است.
