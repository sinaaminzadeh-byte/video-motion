# نواک وب — دو ریلز بی‌نریشن

دو خروجی در `output/video-01` و `output/video-02` قرار دارند. در هر پوشه MP4، کاور، سناریو و SRT وجود دارد؛ کد قابل ویرایش مشترک در `src/render.py` است. صدا صرفاً افکت‌های ترکیب‌شده به‌صورت محلی است. نمونه نشان نواک و رابط ترب رسمی نیستند.

## بازتولید محلی
Python 3.11 و سیستم x86_64 Linux با دسترسی به PyPI مورد نیازند. خروجی imageio-ffmpeg باینری FFmpeg لازم را فراهم می‌کند.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python src/render.py 1
.venv/bin/python src/render.py 2
```

متن با arabic-reshaper و python-bidi شکل‌دهی می‌شود؛ فونت Vazirmatn تحت OFL در `assets` است. تصاویر در اندازه 540×960 ساخته و در رندر به 1080×1920 بزرگ می‌شوند؛ متن نهایی رزولوشن ذاتی 1080 ندارد. به‌جای نصب Remotion و مهارت‌ها از ابزار محلی سبک استفاده شد، بنابراین پروژه Remotion نیست.
